# Semantic Research Paper Search Engine

A semantic search system designed to retrieve relevant research papers based on the meaning and context of a user's query.

## Key Components

* Exploratory Data Analysis and preprocessing
* Text embedding generation
* Semantic similarity search
* Relevant research paper retrieval

## Technologies

Python · Pandas · NumPy · Sentence Transformers · FAISS · Jupyter Notebook

## Files

* `EDA.ipynb` — Data analysis and preprocessing
* `Search_Engine.ipynb` — Semantic search implementation
